Generate Invoice
The invoice amount is automatically calculated by matching the parcel's weight, size category, service type, and route zone to the tariff rate table via an Oracle SQL JOIN. No manual amount entry required.
Note: An invoice can only be generated if the parcel has a route assigned with a zone, and if a tariff rate exists for the parcel's weight band, size, and service type.

Oracle SQL Developer

Database Schema

Third Normal Form (3NF) relational database — 12 tables, 12 sequences, full FK/CHECK/UNIQUE constraints. Run traderoute_oracle_ddl.sql then traderoute_seed_data.sql in Oracle SQL Developer.
Key Oracle SQL Queries
Track a parcel by code
SELECT p.tracking_code, ps.status_name, de.event_type,
       de.event_timestamp, de.location_notes,
       c1.client_name AS sender, c2.client_name AS recipient
FROM       PARCEL p
JOIN       PARCEL_STATUS  ps  ON ps.status_id  = p.status_id
JOIN       CLIENT         c1  ON c1.client_id  = p.sender_id
JOIN       CLIENT         c2  ON c2.client_id  = p.recipient_id
LEFT JOIN  DELIVERY_EVENT de  ON de.parcel_id  = p.parcel_id
WHERE UPPER(p.tracking_code) = UPPER('TR-240601-10001')
ORDER BY de.event_timestamp ASC;
Today's route schedule
SELECT r.route_code, r.route_name,
       d.full_name AS driver, v.registration AS vehicle,
       ra.total_load_kg,
       ROUND(ra.total_load_kg / v.capacity_kg * 100, 1) AS load_pct
FROM   ROUTE_ASSIGNMENT ra
JOIN   ROUTE   r  ON r.route_id   = ra.route_id
JOIN   DRIVER  d  ON d.driver_id  = ra.driver_id
JOIN   VEHICLE v  ON v.vehicle_id = ra.vehicle_id
WHERE  TRUNC(ra.assignment_date) = TRUNC(SYSDATE)
ORDER BY r.route_code;
Auto-calculate invoice from tariff rates
SELECT p.tracking_code, p.weight_kg,
       p.size_category, p.service_type,
       t.rate_zar AS invoice_amount
FROM   PARCEL       p
JOIN   ROUTE_ZONE   rz ON rz.route_id = p.route_id
JOIN   TARIFF_RATE  t
          ON  p.weight_kg     BETWEEN t.weight_band_min AND t.weight_band_max
          AND p.size_category = t.size_category
          AND p.service_type  = t.service_type
          AND rz.zone_id      = t.zone_id
WHERE  p.parcel_id = 1;
Outstanding invoices per client
SELECT c.client_name,
       COUNT(i.invoice_id)  AS invoice_count,
       SUM(i.amount_zar)    AS total_outstanding
FROM   INVOICE i
JOIN   CLIENT  c  ON c.client_id = i.client_id
WHERE  i.payment_status = 'UNPAID'
GROUP BY c.client_name
ORDER BY total_outstanding DESC;
Driver performance this month
SELECT d.full_name,
       COUNT(de.event_id) AS total_deliveries,
       SUM(CASE WHEN de.outcome_code = 'SUCCESS' THEN 1 ELSE 0 END) AS successful,
       ROUND(SUM(CASE WHEN de.outcome_code='SUCCESS' THEN 1 ELSE 0 END)
             * 100.0 / COUNT(de.event_id), 1) AS success_pct
FROM       DRIVER           d
JOIN       ROUTE_ASSIGNMENT ra ON ra.driver_id    = d.driver_id
JOIN       DELIVERY_EVENT   de ON de.assignment_id = ra.assignment_id
WHERE      ra.assignment_date >= TRUNC(SYSDATE,'MM')
GROUP BY   d.full_name
ORDER BY   success_pct DESC;
